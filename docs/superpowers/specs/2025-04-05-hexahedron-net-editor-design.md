# 六面体展开图训练器设计规范

## 项目概述

将现有的 `cube-net-editor.html/js` 替换为基于 `hexahedron.html` 扩展的六面体展开图训练器，专门针对公务员考试图形推理六面体展开图的交互式训练工具。

## 技术架构

### 基础技术栈
- **HTML5单文件**：符合"离线可用"要求
- **Three.js**：3D立方体渲染和折叠动画
- **GSAP**：动画时间轴控制
- **Tailwind CSS**：UI样式（CDN引入）
- **原生Canvas API**：面片手绘系统

### 文件修改清单

| 文件 | 修改内容 |
|------|----------|
| `index.html` | 按钮 href 改为 `hexahedron.html` |
| `app.js` | `window.open` 改为打开 `hexahedron.html` |
| `hexahedron.html` | 完整重写，实现所有核心功能 |

## 核心功能模块

### 1. 11种标准展开图结构

**数据结构定义：**
```javascript
// 面片数据结构
Face {
  id: number,           // 0-5 对应六面
  position: {x, y},     // 在展开图中的网格坐标
  rotation: number,     // 0, 90, 180, 270 (图案旋转角度)
  canvas: HTMLCanvasElement,  // 该面的绘画层
  patterns: Array<Pattern>,   // 图案列表
  color: string         // 背景色
}

// 展开图结构定义
NetStructure {
  type: '1-4-1' | '2-3-1' | '3-3' | '2-2-2',
  variant: number,      // 变体编号
  layout: Array<{faceId: number, gridX: number, gridY: number}>,
  validMoves: Array<MoveRule>
}
```

**展开图类型：**
- **1-4-1型**（6种变体）：中间4个面连成一排，上下各1个面
- **2-3-1型**（3种变体）：2-3-1排列
- **3-3型**（1种）：阶梯状3-3排列
- **2-2-2型**（1种）：阶梯状2-2-2排列

### 2. 移面法交互系统

**A. 垂直滚动移面（滚面法）**
- 操作方式：拖拽某个面，沿垂直方向（上下）滚动
- 视觉反馈：滚动过程中面做90度旋转动画
- 规则逻辑：
  - 面向上滚动90度 → 图案顺时针旋转90度
  - 面向下滚动90度 → 图案逆时针旋转90度
  - 滚动后新位置替换原位置，原位置空白

**B. 平行移面（平移法）**
- 触发条件：当一行有4个连续的面时（1-4-1结构）
- 操作方式：拖拽两端的面向另一端平移
- 视觉反馈：面水平滑动，图案方向保持不变
- 逻辑：两端面可以互换位置

**C. 公共边移面**
- 针对3-3结构和2-2-2结构
- 可以"剪开"公共边，将相连的面同时垂直滚动
- 例如：3-3结构变成1-4-1结构

**移面规则算法：**
- 使用网格坐标系判断面的位置关系
- 垂直滚动：检查目标grid位置是否为空，若为空则交换并旋转图案
- 平行移面：检查一行是否有4个连续面，允许首尾交换
- 有效性验证：移面后检查是否仍构成合法的11种展开图之一

### 3. 面片手绘系统

**画笔工具：**
- 颜色选择：黑、红、蓝、绿（考试常用色）
- 粗细调节：细/中/粗
- 橡皮擦工具

**图案库：**
- 几何图形：实心圆、空心圆、三角形、正方形、菱形、五角星、十字
- 箭头方向：↑↓←→
- 骰子点数：1-6点

**图案方向控制：**
- 每个图案可独立旋转（0°、90°、180°、270°）
- 实时预览

**撤销/重做：**
- 支持Ctrl+Z撤销、Ctrl+Y重做
- 最多保存50步历史

### 4. 3D折叠验证视图

**双模式切换：**
- 编辑模式：2D展开图平面，支持移面和绘画
- 3D验证模式：将当前展开图折叠成立方体，可旋转查看

**折叠动画：**
- 使用GSAP实现平滑过渡
- 高亮显示选中的面

## UI布局

```
+------------------+------------------------+------------------+
|    左侧工具栏    |      中间编辑区        |    右侧预览区    |
+------------------+------------------------+------------------+
| - 展开模式选择   |                        | - 3D立方体预览   |
| - 绘图工具       |    2D展开图编辑        | - 折叠/展开按钮  |
| - 图案库         |    (网格背景)          | - 视角控制       |
| - 颜色选择       |                        | - 提示信息       |
| - 撤销/重做      |                        |                  |
| - 清空操作       |                        |                  |
+------------------+------------------------+------------------+
```

**视觉风格：**
- 背景：深色系（护眼），网格线浅色
- 面片：白色背景，黑色边框，选中时蓝色高亮边框
- 移面动画：面片移动时有阴影提升，旋转时显示旋转箭头指示

## 交互细节

- 鼠标悬停在面片上时，显示该面的名称（前/后/左/右/上/下）
- 拖拽移面时，显示"虚影"表示原位置，实体面跟随鼠标
- 移面操作后自动保存历史记录
- 快捷键：B=画笔、E=橡皮擦、Ctrl+Z=撤销、Ctrl+Y=重做
