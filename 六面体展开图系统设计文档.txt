公考六面体展开图移面法训练器

### 项目概述
开发一个专门针对**公务员考试图形推理六面体展开图**的交互式训练工具。核心功能是可视化**移面法**（垂直滚动移面、平行移面），并支持用户在每个面上**手绘图案**，模拟真实考试中的拆纸盒/折纸盒题型。

### 核心功能模块

#### 1. 11种标准展开图结构支持
必须完整支持公务员考试全部11种六面体展开图：
- **1-4-1型**（6种变体）：中间4个面连成一排，上下各1个面
- **2-3-1型**（3种变体）：2-3-1排列
- **3-3型**（1种）：阶梯状3-3排列  
- **2-2-2型**（1种）：阶梯状2-2-2排列

每种结构可通过下拉菜单切换，切换时有过渡动画。

#### 2. 移面法交互系统（重点）

**A. 垂直滚动移面（滚面法）**
- 操作方式：用户拖拽某个面，沿垂直方向（上下）滚动
- 视觉反馈：滚动过程中面做90度旋转动画，图案方向随滚动改变
- 规则逻辑：
  - 面向上滚动90度 → 图案顺时针旋转90度
  - 面向下滚动90度 → 图案逆时针旋转90度
  - 滚动后新位置替换原位置，原位置空白

**B. 平行移面（平移法）**
- 触发条件：当一行或一列有4个连续的面时（1-4-1结构的中间行）
- 操作方式：拖拽两端的面向另一端平移
- 视觉反馈：面水平滑动到目标位置，**图案方向保持不变**
- 逻辑：两端面可以互换位置，用于判断相对面关系

**C. 公共边移面**
- 针对3-3结构和2-2-2结构
- 可以"剪开"公共边，将相连的面同时垂直滚动
- 例如：3-3结构中，将上面3个面整体滚动变成1-4-1结构

#### 3. 面片手绘系统（画笔功能）
每个面片支持Canvas手绘：
- **画笔工具**：
  - 不同颜色画笔（黑、红、蓝、绿，契合考试常用色）
  - 不同粗细（细/中/粗）
  - 直线工具（用于画十字、对角线）
  - 基础图形印章（圆形、三角形、正方形、箭头）
  
- **图案库**（针对考试高频图案）：
  - 几何图形：实心圆、空心圆、三角形、正方形、菱形、五角星、十字
  - 箭头方向：↑↓←→（带箭头线，可调节长度和弯曲度）
  - 骰子点数：1-6点（标准骰子布局，用于相对面判断练习）
  - 阴影图案：斜线阴影、网格阴影（如图1中的三角形阴影）

- **图案方向控制**：
  - 每个图案可独立旋转（0°、90°、180°、270°）
  - 实时预览旋转后的效果

#### 4. 3D折叠验证视图
- **双模式切换**：
  - **编辑模式**：2D展开图平面，支持移面和绘画
  - **3D验证模式**：Three.js渲染，将当前展开图折叠成立方体，可旋转查看
  
- **折叠动画**：
  - 从展开图到立方体的展开/折叠过程要有流畅动画
  - 高亮显示选中的面在3D模型中的位置

#### 5. 考试训练模式
**预设题库**（基于你提供的图片）：
- **相对面判断题**：给定展开图，要求找出三组相对面（用相同颜色标记）
- **相邻面判断题**：给定一个面，判断哪些面与之相邻
- **方向判断题**：给定带箭头的面，折叠后判断箭头指向
- **图案匹配题**：左侧给展开图，右侧给4个3D选项，选择正确的折叠结果

**智能提示**：
- 移面操作后自动判断是否为有效的六面体展开图
- 提示相对面关系（如"1和4是相对面，折叠后不会相邻"）
- Z字形法则视觉辅助（用虚线连接Z字形两端提示相对面）

### 技术实现规格

**前端框架**：HTML5 + Tailwind CSS + 原生JavaScript

**核心库**：
- **Three.js**：3D立方体渲染和折叠动画
- **Fabric.js** 或 **原生Canvas API**：面片的手绘编辑和图案渲染
- **GSAP**：移面动画、折叠动画的时间轴控制

**数据结构**：
```javascript
// 面片数据结构
Face {
  id: number,           // 0-5 对应六面
  position: {x, y},     // 在展开图中的网格坐标（以格子为单位）
  rotation: number,     // 0, 90, 180, 270 (图案旋转角度)
  canvas: HTMLCanvasElement,  // 该面的绘画层
  patterns: Array<Pattern>,   // 图案列表（支持多图层）
  color: string         // 背景色
}

// 展开图结构定义
NetStructure {
  type: '1-4-1' | '2-3-1' | '3-3' | '2-2-2',
  layout: Array<{faceId: number, gridX: number, gridY: number}>,  // 面在网格中的位置
  validMoves: Array<MoveRule>  // 该结构支持的移面规则
}
```

**移面规则算法**：
- 使用网格坐标系（gridX, gridY）判断面的位置关系
- 垂直滚动：检查目标grid位置是否为空，若为空则交换位置并旋转图案
- 平行移面：检查一行是否有4个连续面，允许首尾交换
- 有效性验证：移面后检查是否仍构成合法的11种展开图之一

### UI/UX设计规范

**界面布局**（从左到右）：
1. **左侧面板**：展开图编辑区（网格背景，可拖拽面片）
2. **中间面板**：工具栏（移面模式切换、画笔工具、图案库）
3. **右侧面板**：3D预览区 + 考试提示

**视觉风格**：
- 背景：深色系（护眼），网格线浅色
- 面片：白色背景，黑色边框，选中时蓝色高亮边框
- 移面动画：面片移动时有阴影提升，旋转时显示旋转箭头指示

**交互细节**：
- 鼠标悬停在面片上时，显示该面的名称（前/后/左/右/上/下）
- 拖拽移面时，显示"虚影"表示原位置，实体面跟随鼠标
- 移面操作后自动保存历史记录（支持Ctrl+Z撤销）

### 输出要求
- 单文件HTML实现（便于分享使用）
- 响应式设计（支持平板横屏练习）
- 离线可用（所有资源内联或CDN）

### 扩展功能（可选）
- **截图导出**：将当前展开图导出为PNG，方便做题分享
- **打印模式**：生成A4纸打印友好的练习题版式
- **计时器**：模拟考试环境，记录解题用时

这个Prompt完整涵盖了**移面法教学**（垂直滚动、平行移面、公共边移面）、**11种展开图结构**、以及**手绘功能**三大核心需求。
